# Бот-карта городов

Телеграм-бот, который показывает города на карте.

## Запуск

1. `pip install -r requirements.txt`
2. В `config.py` вписать токен бота
3. `python bot.py`

## Команды

- `/start` — запуск
- `/help` — помощь
- `/show_city London` — показать город на карте
- `/remember_city London` — запомнить город
- `/show_my_cities` — все сохранённые города на карте
- `/set_color красный` — цвет маркеров (на русском или английском)
- `/countries` — список стран в базе
- `/country Россия 20` — города страны на карте
- `/population 10000000 30000000` — города по численности населения
- `/filter Япония 1000000` — страна + население
- `/weather Москва, Париж` — текущая погода (met.no API)
- `/time Токио, Нью-Йорк` — местное время в городах

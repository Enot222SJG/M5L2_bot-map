# Бот-карта городов

Телеграм-бот, который показывает города на карте.

## Запуск

1. `pip install -r requirements.txt`
2. В `config.py` вписать токен бота
3. `python bot.py`

## Команды

- `/start` — запуск
- `/help` — помощь
- `/show_city London` — показать город на карте
- `/remember_city London` — запомнить город
- `/show_my_cities` — все сохранённые города на карте
